# KneuraSense ML Pipeline Setup Guide

This folder contains the Python scripts to extract sensor data from the Next.js Prisma database into CSV files for Edge Impulse training.

## How to Set Up the Environment (First Time or New PC)
To avoid conflicting with global Python packages, you must run this script inside an isolated virtual environment.

#Use this command if you ever go too deep and want to move back one folder 
##(e.g., from ml-pipeline back to KneuraSense), type: `cd ..`

1. Open your terminal and navigate to this folder:
   `cd ml-pipeline`

2. Create a clean virtual environment:
   `python -m venv venv`

3. Activate the environment:
   - On Windows: `.\venv\Scripts\activate`
   - On Mac/Linux: `source venv/bin/activate`

4. Install all required dependencies at once using the requirements file:
   `pip install -r requirements.txt`

## How to Run the Script
1. Ensure your environment is active (you should see `(venv)` in the terminal).
2. Ensure you have a `.env` file in the root `KneuraSense` folder containing your `DATABASE_URL`.
3. Update the `START_TIME` and `END_TIME` inside `export_data.py`.
4. Run the script:
   `python export_data.py`

## How to Update requirements.txt
If you ever install a new Python package (e.g., `pip install numpy`) and want to save it to the requirements file so you don't forget it, run this command:
   `pip freeze > requirements.txt`
